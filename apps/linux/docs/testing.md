# 测试与界面验收

最后验收：2026-11-19。Python 3.12、GTK 4.14、libadwaita 1.5、X11 会话。

## 完整检查

```bash
python3 scripts/check.py

# 同时生成五个页面的深浅色、紧凑窗口、设置和全屏遮罩截图
python3 scripts/check.py --screenshots /tmp/timebook-ui
```

脚本依次执行 Python 编译检查、安装/启动 shell 脚本语法检查和全部 unittest。它设置 `TIMEBOOK_REQUIRE_UI=1`，缺少 GTK 或显示器时明确失败，不能把跳过 GUI 的结果当作完整验收。截图额外需要 X11 和 ImageMagick `import`。

只跑 `python3 -m unittest discover -s tests -v` 时，无显示器环境可以运行核心测试，但会明确跳过 UI 测试。该命令的成功不代表完成桌面验收。

## 修复并覆盖的行为

- 打开/重载设置不会自动排除应用；显式选择后才添加，控件更新避开模型通知中的重入。
- 应用选择不被周期刷新重置；未来小时禁用，小时格可用键盘操作。
- 今日、时间线、统计与导出都包含进行中的应用段；数据落库前后不重复计数。
- 区间查询裁剪起止边界，跨午夜使用分到各自日期，热力图与趋势合计一致。
- 分类环形图和百分比使用浏览网站时长为分母，不混入无域名的应用时长。
- 番茄继续时立即显示正确剩余时间；暂停期间跳过不会计入暂停时间；运行中不能更改预设。
- 喝水为零时禁用减量；每日限额进度实时更新，未启用时不显示无含义的进度轨道。
- 主窗口和设置各有导出反馈；写入失败有提示；多次导出使用独立文件名；CSV 多行标题不会多算行数。
- 托盘不可用时关闭窗口会退出；可用时隐藏。隐藏启动后再次激活能够打开窗口。
- `--no-track` 启动独立预览实例，避免误连已有用户窗口，不采集也不覆盖个人快照。
- 休息遮罩以所在显示器尺寸创建，映射后请求全屏；跳过、Esc、倒计时结束都会清理定时器。
