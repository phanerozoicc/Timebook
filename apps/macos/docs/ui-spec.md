## 1. 设计原则

1. **菜单栏优先（glanceable）**：核心信息（今日时长/番茄倒计时）在菜单栏一眼可得；
   主窗口只承担"回看与分析"。
2. **数据无表格感**：所有数字配进度/条形/环/热力等可视化，不做纯数字罗列。
3. **安静的深色友好**：默认跟随系统外观，色彩只用语义位（等级/分类/状态），
   不做装饰性用色。
4. **中文为源语言**，English 全量覆盖，`跟随系统/中文/English` 三档可切。
5. **零打断**：所有提醒都是通知（warn 语义），不弹模态；唯一的模态是用户
   主动触发的 20 秒微休息遮罩。

## 2. 布局

### 2.1 菜单栏（MenuBarExtra · window 样式）

- 标签位（宽度自适应，monospaced digit）：
  - 默认：今日累计 `2h07m`（<1h 显示 `34m`，<1m 显示 `0s`）
  - 暂停：`⏸`
  - 番茄运行：`🍅 24:31`；番茄暂停：`🍅 ⏸ 24:31`
- 下拉（260pt 宽）自上而下：今日合计行 → 当前应用行（caption, secondary）→
  限额 Gauge（仅启用限额且 >1 分钟时出现）→ 分隔线 → 番茄区（阶段行 +
  控制按钮 + 预设 Picker）→ 分隔线 → 喝水行（+1 杯 / cups/goal）→
  微休息按钮 → 分隔线 → 打开主窗口 / 设置 → 分隔线 → 暂停记录 / 退出。

### 2.2 主窗口（760×560 起，可缩放）

顶部 4 段 segmented：`今日 / 专注 / 统计 / 时间线`。

| 页 | 内容自上而下 |
|---|---|
| 今日 | 大数字合计（40pt rounded semibold）+ 疲劳等级卡 + 分类条形 + 按网站条形 + 按应用条形 |
| 专注 | 环形进度（190pt）+ 轮次圆点 + 控制按钮 + 预设 radio + 自动开始开关 + 四张统计卡（完成/专注/喝水/连续活跃）+ 分心记录列表 |
| 统计 | 周/月 segmented + 三张汇总卡（合计/活跃天日均/活跃天）+ 每日趋势柱状图 + 分类环形图 + 12 周热力图 |
| 时间线 | 当日分段列表：起止(HH:mm) / 时长 / 应用 / 域名 / 窗口标题（若开启采集） |

### 2.3 微休息遮罩

全屏 NSPanel（screenSaver 层、跟随所有空间）：深色渐变背景 + 中央 220pt
倒计时环（绿 0x6FAF8C）+ 大数字 + 引导文案（看 6 米外/眨眼/深呼吸/活动肩颈）
+ `跳过` 按钮。20 秒自动关闭，或跳过。

### 2.4 设置（Form grouped，520×620）

五段：记录 / 每日限额 / 提醒 / 排除应用 / 外观与数据。
导出按钮行内反馈状态文本（`已导出 N 行 ✓`）。

## 3. 设计 token

### 3.1 颜色（语义位）

| 用途 | 值 |
|---|---|
| 疲劳等级 L1–L10 | 0x6FAF8C → 0x585E68（暖色渐变，每级一色） |
| 分类 9 色 | 社交 0xE1306C · 视频 0xFF0000 · 资讯 0xF59E0B · 购物 0x10B981 · 工作 0x3B82F6 · 学习 0x8B5CF6 · 娱乐 0xF97316 · 邮件 0x06B6D4 · 其他 0x6B7280 |
| 热力图 7 档 | 0x262A35 → 0xE2B15C（0h → ≥6h） |
| 番茄环 | 专注=orange · 短休=green · 长休=blue · 待机=secondary |
| 限额 Gauge | <100% orange · ≥100% red |
| 达成喝水目标 | 0x10B981 |

### 3.2 字体

- 大数字：`.system(size: 40, weight: .semibold, design: .rounded)` + monospacedDigit
- 环内倒计时：36pt 同上；遮罩大数字：84pt
- 页面标题：`.headline`；正文 `.callout`；辅助 `.caption/.caption2` + secondary

### 3.3 组件

- 条形图：`Capsule` 轨道 quaternary + tint 进度，高度 10，标签列宽 170，数值列右对齐 90
- 统计卡：`RoundedRectangle 12` + `.background.secondary`，内边距 14
- 等级卡：等级色 6–18% 透明度底 + 52pt 圆形徽章（L 级别数字）
- 环：线宽 10（主窗）/12（遮罩），圆头端帽，-90° 起始

## 4. 状态

| 状态 | 表现 |
|---|---|
| 记录中 | 菜单栏显示今日时长；当前应用行实时更新 |
| 空闲 | 当前应用行显示「空闲中」；不产生数据；提醒计数清零 |
| 已暂停 | 菜单栏 `⏸`；设置与菜单均可恢复 |
| 番茄 work/short/long | 菜单栏倒计时接管；环按阶段着色 |
| 番茄 -ready | 按钮显示「开始+阶段名」，环保持满格 |
| 限额达标 | Gauge 变红 + 通知；菜单栏不额外变化 |
| 空数据（新装） | 图表区显示空轴/「还没有足够的数据」文案，不崩溃 |

## 5. 交互与快捷路径

- 所有提醒（限额/休息/喝水/番茄）都走系统通知；番茄首次开始时请求通知授权
- 微休息入口：菜单栏 + 专注页；结束后重置"连续活跃"计数
- 番茄休息期 / 空闲期自动重置休息提醒计数（与休息联动）
- 排除的应用完全不落库；暂停时不产生任何数据

## 6. 无障碍与本地化

- 全部文本走 `T(zh, en)` 双语；数字 monospacedDigit 防跳动
- 控件均用系统组件（Toggle/Picker/Button/Gauge），自带 AX 标签与键盘导航
- 颜色仅作强化，信息同时有文字承载（等级名/分类名/百分比）
