# 时账 Timebook · Linux 界面规范 / UI Spec (Linux)

> 本文描述 **GTK4 + libadwaita** 版本的界面结构、设计 token 与状态行为，供实现、验收与后续移植参考。
> 所有数值均取自代码，修改界面时请同步更新本文。
>
> Source of truth：`timebook/ui/theme.py`、`timebook/ui/main_window.py`、`timebook/ui/pages/*.py`、`timebook/ui/widgets.py`。

---

## 1. 设计原则 / Principles

1. **一眼看到今天**：今日总时长是最大字号；所有页面共享「侧边栏 + 顶栏 + 页面栈」骨架。
2. **数据即界面**：不做装饰性插画；环、柱、热力格、24 格都直接编码数据。
3. **本地优先**：不使用网络图片、在线字体或远程主题；颜色和字体全部来自系统与本地 token。
4. **颜色 + 文字双编码**：等级、阶段、荒/守都同时给出颜色和文字，不单靠颜色传达状态。
5. **克制的品牌色**：番茄红只用于主操作、选中态与图表；关键数字采用系统前景色；其余用系统前景色的透明度层级。

## 3. 全局布局 / Shell

```text
┌──────────────────────────────────────────────────────────────┐
│ HeaderBar：页面标题（19/800）      [暂停记录] [设置] [导出]   │
├───────────────┬──────────────────────────────────────────────┤
│ 侧边栏 200px  │ Gtk.Stack（crossfade 160ms）                 │
│               │                                              │
│ ● 品牌 logo   │  ┌────────────────────────────────────────┐  │
│   时账        │  │ Page（Gtk.ScrolledWindow，纵向滚动）    │  │
│   Timebook…   │  │  margin 18/24/22/22，spacing 16         │  │
│               │  │                                        │  │
│ 今日          │  │  卡片 / Hero / 图表 …                   │  │
│ 专注          │  │                                        │  │
│ 统计          │  │                                        │  │
│ 时间线        │  └────────────────────────────────────────┘  │
│ 丢小时        │                                              │
│               │                                              │
│ [今日合计卡]  │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

- **顶栏**：`Gtk.HeaderBar`；标题控件是当前页名（中文/English 随语言）；右侧依次为暂停切换、设置（`emblem-system-symbolic`）、导出（`document-save-symbolic`）。
- **侧边栏**：品牌头（34×34 程序化 logo + 「时账」/「Timebook · 本地优先」）→ `Gtk.ListBox` 五项导航（图标 17px + 文案 14px）→ 弹性空白 → 底部迷你卡（「今日合计」、22/800 品牌色数值、当前等级）。
- **导航选中态**：背景品牌色 16%，文字/图标品牌色、700；hover 前景色 6%；行圆角 12、外边距 1×8、内边距 2×6。
- **页面栈**：`Gtk.Stack` crossfade 160ms；切换导航时刷新目标页（`force=True`）。
- **快捷键**：`Ctrl+1` 今日、`Ctrl+2` 专注、`Ctrl+3` 统计、`Ctrl+4` 时间线、`Ctrl+5` 丢小时。导航行 tooltip 同时展示 `页面 · Ctrl+N`。
- **关闭窗口**：默认隐藏窗口、保留托盘与采集（无托盘时退出）；这是菜单栏应用的常驻行为。

## 4. 五个页面 / Pages

### 4.1 今日 Today（`pages/today.py`）

| 区块 | 内容与组件 |
|---|---|
| Hero | 左上「今日屏幕时间」+ 右上日期（中文 `%Y年%m月%d日` / 英文 `%a, %b %d`）；44/600 今日合计（compact，如 `2h07m`）；副标题（昨日对比/新开始文案）；8px 品牌胶囊条 |
| 疲劳等级卡 | 54px 等级徽章（等级色淡底 + 系统前景数字）；`L{level} {name}`（22/600）；等级提示文案（可换行）；右侧「距 Lx 还有 …」；8px 等级色胶囊条 |
| 分类占比 | SectionHeader（`view-grid-symbolic` + 「分类占比」）；最多 9 条 BarRow，颜色取分类色；空状态「今天还没有浏览记录。」 |
| 按网站 | SectionHeader（`network-server-symbolic` + 「按网站」/「仅浏览器」）；最多 8 条，颜色取站点分类色；空状态「还没有网站记录，去浏览器逛逛？」 |
| 按应用 | SectionHeader（`applications-system-symbolic` + 「按应用」）；最多 8 条，品牌色；空状态「还没有应用记录。」 |

数据刷新以 `(total, len(rows))` 为签名，未变化时不重建列表；今日合计会叠加尚未结账的当前段，所以数字每 2 秒跳动。

### 4.2 专注 Focus（`pages/focus.py`）

1. **主卡**：196px 番茄环（线宽 11）→ 阶段说明（居中）→ 轮次圆点 → 控制按钮（主按钮 / 跳过 / 结束）→ 预设（默认经典 40/5、冲刺 15/3、深度 50/10、自定义 30/5）→ 自动开始休息 / 自动开始下一轮两个开关。
2. **四张统计卡**（等宽一行）：今日完成（`N 🍅`，品牌色）、专注时长（健康绿）、喝水（`cups/goal`，水蓝）、连续活跃（冷静蓝）。
3. **喝水卡**：「💧 喝水」+ `N / goal 杯`；`+1 杯` / `−1 杯`；8px 水蓝胶囊进度。
4. **分心记录卡**：SectionHeader（`dialog-warning-symbolic` +「分心记录」+「本次专注期间」）；按此次专注开始以来的应用使用取前 6 个（>20 秒），品牌色 BarRow，标签列宽 150；无数据时显示空状态。

**环内文字**：运行中显示 `MM:SS` 剩余；`ready`/`idle` 显示该阶段总时长 `MM:00`。环下小字为阶段名（`待机/专注/短休/长休/准备…`）。

**阶段说明**：非待机时 `「{阶段} · 第 {round}/{rounds} 轮」`；待机时「待机 · 准备好就开始第一个番茄」。

**主按钮文案**：待机「开始专注」；ready「开始{阶段}」；运行中「暂停」；已暂停「继续」。跳过仅在运行中可点；结束在非待机时可点。

**轮次圆点**：已完成 = 实心；当前 = 描边 + 内点；未来 = 白色 18% 描边；颜色随阶段色。

### 4.3 统计 Stats（`pages/stats.py`）

1. **范围切换**：胶囊分段控件「最近 7 天 / 最近 30 天」；右侧区间说明 `MM/DD – MM/DD`。
2. **三张汇总卡**：区间合计（品牌）、活跃天日均（健康绿）、活跃天数（冷静蓝）。
3. **每日趋势**：SectionHeader（`office-calendar-symbolic` +「每日趋势」），尾注「峰值 MM/DD · 时长」；180px 品牌柱状图；7 天用「一二三四五六日」标签，30 天用 `MM/DD`。
4. **分类占比**：176px 环形图 + 图例（9px 色点、名称列 84px、90×6 胶囊条、右对齐百分比）。
5. **热力图**：SectionHeader「最近 12 周」；12×7 网格（周一在上）；下方「共 N 天有记录 · 合计 …」。

### 4.4 时间线 Timeline（`pages/timeline.py`）

- 顶部：左侧「今日 N 段 · 合计 …」，右侧标题采集状态（「已开启窗口标题采集」/「窗口标题采集已关闭（设置 → 记录）」）。
- 列表卡（内边距 2）：每行 = 起止时间（112px，等宽）+ 时长（64px 右对齐）+ 应用名/窗口标题（可省略号）+ 域名 Pill（取站点分类色）。
- 最多渲染 400 段；空状态「今天还没有记录。」。
- 以 `(段数, 首段开始时间, 总时长)` 为签名避免无谓重建。

### 4.5 丢小时 Forfeit（`pages/forfeit.py`）

1. **三张汇总卡**：今日荒废（警示红）、连续干净天（健康绿）、最近 30 天（琥珀）。
2. **24 格**：3 行 × 8 列，原生 ToggleButton、最小 44px、间距 6、圆角 8；每格显示小时与荒/守文字；未来小时禁用，当前小时描边；支持 Tab、空格与点击改判。图例：「荒：分心应用占用」「守：清醒使用」「当前小时」。
3. **最近 14 天**：130px 警示红柱状图，尾注「每天荒废小时数」。
4. **分心应用**：名单（应用 id + 移除按钮）；下拉选择最近用过的应用 +「加入名单」；空状态「还没有设置分心应用。从下面最近用过的应用里挑一个。」
5. **分心类目**：FlowBox 五列，每类一个开关（不含「其他」），前有色点。
6. **自定义分心网站**：域名后缀列表 + 输入框（placeholder `例如 douyin.com`）+「添加」。

## 5. 状态与反馈 / States

### 5.1 采集全局状态

| 状态 | 触发 | 界面表现 | 数据行为 |
|---|---|---|---|
| **记录中 Recording** | 前台窗口存在、未暂停、未空闲、未锁屏、不在排除名单 | 侧边栏今日合计每 2 秒更新；托盘标签显示今日时长；暂停按钮为「暂停记录」 | 当前段只在切换/退出时落库；`today_total` 叠加未结账段 |
| **空闲 Idle** | 键鼠空闲 ≥ 设置阈值（默认 120 秒） | 托盘状态「空闲中」；界面保留已有数据 | 当前段在「开始空闲之前」结账；空闲期间不新增数据；连续活跃计时清零 |
| **暂停 Paused** | 顶栏/设置/托盘的暂停开关 | 按钮变为「继续记录」且处于选中态；托盘标签 `⏸`；设置开关同步 | 立即结账当前段；暂停期间采集 tick 不落库 |
| **排除应用 Excluded** | 当前应用命中排除名单 | 暂无专门提示 | 当前段关闭且不记录 |
| **锁屏/熄屏 Screen locked** | `XScreenSaverQueryInfo` 报告 blank/locked | 与空闲相同 | 关闭当前段且不记录 |
| **采集不可用 No X11 / Wayland** | libX11 不可用、无 `DISPLAY` 或只能看到 Wayland 原生窗口 | 界面仍可打开、可看历史与番茄；不再产生新段 | `active_window()` 返回 `None`，采集循环静默跳过 |
| **托盘不可用 No tray** | 无 AppIndicator | 仅主窗口；关闭窗口正常退出 | 退出前结账当前段 |

### 5.2 番茄状态机

| 阶段 | 环色 | 环内文字 | 主按钮 | 跳过 | 结束 | 进入下一阶段 |
|---|---|---|---|---|---|---|
| `idle` 待机 | `#8A8F98` | 工作时长 `MM:00` | 开始专注 | 禁用 | 禁用 | 点击开始 → `work` |
| `work` 专注 | `#F0663F` | 剩余 `MM:SS` | 暂停 | 可用 | 可用 | 倒计时结束 → `short`/`long`；跳过也进入休息 |
| `work-ready` 准备专注 | `#F0663F` | 工作时长 `MM:00` | 开始专注 | 禁用 | 可用 | 点击 → `work` |
| `short` 短休 | `#53B987` | 剩余 `MM:SS` | 暂停 | 可用 | 可用 | 结束 → `work` 或 `work-ready` |
| `short-ready` 准备短休 | `#53B987` | 短休时长 `MM:00` | 开始短休 | 禁用 | 可用 | 点击 → `short` |
| `long` 长休 | `#5B8DEF` | 剩余 `MM:SS` | 暂停 | 可用 | 可用 | 结束 → `work` 或 `work-ready` |
| `long-ready` 准备长休 | `#5B8DEF` | 长休时长 `MM:00` | 开始长休 | 禁用 | 可用 | 点击 → `long` |
| 运行中已暂停 | 阶段色不变 | 冻结的剩余时间 | 继续 | 可用 | 可用 | 点击继续 → 原阶段 |

- 第 `rounds` 轮工作结束后进入长休（经典 4 轮、冲刺 4 轮、深度 3 轮、自定义 4 轮），否则短休。
- 预设仅在待机时可更换，防止运行中时长与统计口径发生变化。喝水为 0 杯时禁用减量按钮。
- 自动开始休息默认 **开**；自动开始下一轮默认 **关**；关闭时进入 `*-ready`，等待手动开始。
- 进入休息阶段会重置「连续活跃」计时；若设置开启（默认开），短休/长休开始时弹出 20 秒全屏微休息遮罩。以当前显示器逻辑尺寸创建，在窗口映射后再次请求全屏，支持跳过、Escape 与倒计时结束关闭。

### 5.4 反馈

- 导出：调用窗口内的 Adw Toast「已导出 N 行明细与周报」，附「打开文件夹」；写入失败显示错误并可重试。
- 设置保存：即时写入 SQLite，无「保存」按钮；`Settings` 每次实时读取，改动立即影响采集。
- 图表更新：页面刷新由 2 秒 UI timer 驱动；时间线等重列表用签名跳过无变化重建。

## 6. 无障碍 / Accessibility

- **键盘**：`Ctrl+1..5` 切页；所有按钮/开关/输入框均可 Tab 聚焦并操作；ListBox 导航支持方向键。
- **语义控件**：优先使用 `Gtk.Button` / `Gtk.Label` / `Gtk.Switch` / `Adw.SwitchRow`，屏幕阅读器可获得名称与状态；图标按钮（设置、导出）带中文 tooltip。
- **不单靠颜色**：等级同时显示 `Lx + 名称 + 文案`；番茄阶段同时显示文字；荒/守有图例文字；热力图有数值说明。
- **对比度**：正文使用系统前景色；品牌色主要承载大字号数字与图形。浅色/深色主题由 libadwaita 的 `@window_fg_color` 透明度层级适配，不在代码中写死背景。
- **缩放的边界**：窗口最小 860×600；页面整体纵向滚动；长文本使用省略号或换行；图表用 cairo 矢量绘制，高 DPI 不模糊。
- **语义与边界**：计时环与分类合计采用原生标签，24 小时格采用原生切换按钮；柱状图提供数值文本摘要。热力图仍没有逐格键盘浏览，未声称完成屏幕阅读器人工验收。
- **动效**：仅页面切换 crossfade 160ms；没有自动播放动画或闪烁内容。

---

## 7. 双语 / Bilingual

- 语言选项：`auto` / `zh` / `en`（设置 → 外观与数据 → 语言），存储键 `language`。
- `auto` 读取 `LC_ALL` / `LC_MESSAGES` / `LANGUAGE` / `LANG`，以 `zh` 开头即中文，否则英文（`core/l10n.py`）。
- 已本地化：侧边栏导航与顶栏页面标题、番茄阶段名与提示、番茄/休息/限额/喝水通知、微休息遮罩、Markdown 周报；日期在今日 Hero 使用中文 `%Y年%m月%d日` / 英文 `%a, %b %d`。托盘与导出 Toast 文案也支持双语。
- 品牌与产品名保持 **「时账 Timebook」**；侧边栏副标题固定为「Timebook · 本地优先」。
- **现状说明**：五个页面的正文标签、区块标题、空状态，以及设置窗口的选项文案目前均为中文硬编码；新增文案应统一走 `core.l10n.T(zh, en)`，避免继续扩大缺口。
- 数字与时长格式：`models.fmt_duration` 提供 compact（`2h07m` / `34m`）与完整（`2 小时 7 分` / `2h 7m`）两种；数值使用等宽数字（tnum）。
